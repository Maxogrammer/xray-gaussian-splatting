# Трехмерное гауссово сплэттинг-моделирование по ограниченному числу ракурсов для компьютерной томографии

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![PyTorch 2.0+](https://img.shields.io/badge/PyTorch-2.0+-ee4c2c.svg)](https://pytorch.org/)

Реализация дифференцируемого томографического пайплайна на основе 3D Gaussian Splatting (3DGS) и аналитического проецирования лучей по закону Бугера — Ламберта — Бера. Проект исследует сходимость непрерывных радиационных гауссиан при решении некорректной обратной задачи КТ-реконструкции в условиях разреженных угловых данных (32 ракурса) с динамическим контролем топологии гауссиан.

---

## 1. Физико-математическая постановка задачи

При рентгеновском сканировании ослабление монохроматического пучка вдоль луча $L_j = \{\mathbf{r}(t) = \mathbf{o}_j + t \mathbf{d}_j \mid t \in \mathbb{R}\}$ описывается законом Бугера — Ламберта — Бера:

$$I_j = I_0 \exp\left( -\int_{L_j} \mu(\mathbf{r}) \, dt \right)$$

Переход к логарифмической шкале проекционной плотности линеаризует задачу:

$$y_j = -\ln\left(\frac{I_j}{I_0}\right) = \int_{L_j} \mu(\mathbf{r}) \, dt$$

Вместо дискретизации трехмерного пространства на регулярную воксельную сетку плотность среды $\mu(\mathbf{r})$ аппроксимируется ансамблем из $N$ ориентированных 3D-эллипсоидов:

$$\mu(\mathbf{r}) = \sum_{i=1}^N \sigma_i \exp\left( -\frac{1}{2} (\mathbf{r} - \boldsymbol{\mu}_i)^T \mathbf{\Sigma}_i^{-1} (\mathbf{r} - \boldsymbol{\mu}_i) \right)$$

где:
* $\boldsymbol{\mu}_i \in \mathbb{R}^3$ — пространственный центр $i$-й гауссианы.
* $\sigma_i \ge 0$ — локальный коэффициент линейного ослабления (плотность).
* $\mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{S}_i^T \mathbf{R}_i^T$ — ковариационная матрица, параметризованная через масштабы $\mathbf{S}_i = \mathrm{diag}(\exp(\mathbf{s}_i))$ и кватернионы вращения $\mathbf{q}_i$.

---

## 2. Аналитическое проецирование

Поскольку интеграл от многомерного нормального распределения вдоль прямой линии вычисляется в замкнутом виде, расчет ослабления не требует численного суммирования вдоль луча.

Подставляя параметризацию луча $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ в квадратичную форму гауссианы, получаем скалярный интеграл:
$$\int_{-\infty}^{+\infty} \exp\left( -\frac{1}{2} (a t^2 + 2b t + c) \right) dt = \sqrt{\frac{2\pi}{a}} \exp\left( -\frac{1}{2} \left( c - \frac{b^2}{a} \right) \right)$$
где коэффициенты квадратичной формы можно рассчитать векторизованно через тензорные свертки (`torch.einsum`):
- $a = \mathbf{d}^T \mathbf{\Sigma}^{-1} \mathbf{d}$
- $b = \mathbf{d}^T \mathbf{\Sigma}^{-1} (\mathbf{o} - \boldsymbol{\mu})$
- $c = (\mathbf{o} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{o} - \boldsymbol{\mu})$

Аналитический градиент функции потерь распространяется на параметры эллипсоидов напрямую через вычислительный граф `PyTorch Autograd`.

В итоге вычисление проекционной плотности (яркости пикселя детектора) становится аналитическим, а благодаря дифференциальному программированию, главным образом `autograd`, можно получить изменения параметров гауссиан для более точного соответствия итоговым изображениям. Тем самым восстанавливается исходный сканируемый объект.

---

## 3. Функция потерь и регуляризация

Оптимизация параметров проводится методом градиентного спуска (Adam) с разделением скоростей обучения ($\eta_{\boldsymbol{\mu}}$ для миграции центров, $\eta_{\text{rest}}$ для формы и плотности):

$$\mathcal{L} = \frac{1}{|B|} \sum_{j \in B} (\hat{y}_j - y_j)^2 + \lambda_{L1} \sum_{i=1}^N \sigma_i + \lambda_{\text{vol}} \sum_{i=1}^N \prod_{k=1}^3 s_{i,k} + \lambda_{\text{aspect}} \sum_{i=1}^N \ln^2\left(\frac{s_{i,\max}}{s_{i,\min} + \varepsilon}\right)$$

1. $\mathcal{L}$ — невязка синтезированных и истинных рентгеновских проекций.
2. $L_1$ (через $\lambda_{L1}$) — подавление паразитных полупрозрачных гауссиан в пустом пространстве.
3. Штраф объёма (через $\lambda_{\text{vol}}$) — штраф за раздувание эллипсоидов, предотвращающий поглощение всей сцены одной массивной гауссианой.
4. Штраф за анизатропность (через $\lambda_{\text{aspect}}$) — штраф за вырождение эллипсоидов в бесконечно тонкие «иглы».

---

## 4. Динамический контроль плотности

Каждые 64 шага оптимизации геометрия модели перестраивается по накопленным нормам градиентов центров:
- Клонирование: гауссианы малого размера ($s_{\max}$ меньше порога) с высоким градиентом положения ($\|\nabla_{\boldsymbol{\mu}}\|$ больше порога) дублируются для насыщения мелких структур.
- Расщепление: крупные гауссианы ($s_{\max}$ больше порога) с высоким градиентом делятся на две меньшие с уменьшением масштаба и сдвигом центров вдоль главной оси.
- Прунинг: все точки с плотностью ниже порога $\sigma_i$ безвозвратно удаляются из вычислительного графа.

## 5. Результаты экспериментов и границы применимости

Эксперимент проводился на синтетическом многослойном фантоме (кожура $\mu=0.8$, мякоть $\mu=0.3$, центральное ядро $\mu=1.0$, две воздушные полости $\mu=0.0$) при разрешении детектора $128 \times 128$ и $M = 32$ проекциях.

### Динамика обучения (6 эпох):

| Эпоха | Число гауссиан ($N$)  | Средний Loss |   Скорость   | Примечание                                          |
| :---: | :-------------------: | :----------: | :----------: | :-------------------------------------------------- |
|  01   | $10\,000 \to 10\,480$ |   0.207113   | 0.40 шагов/с | Инициализация и первый цикл клонирования            |
|  02   | $10\,480 \to 10\,717$ |   0.104474   | 0.38 шагов/с | Формирование базового объема фантома                |
|  03   | $10\,717 \to 10\,839$ |   0.066920   | 0.37 шагов/с | Локализация плотного ядра                           |
|  04   | $10\,839 \to 10\,881$ |   0.042493   | 0.37 шагов/с | Стабилизация пространственного распределения        |
|  05   | $10\,881 \to 2\,669$  |   0.027187   | 0.37 шагов/с | Масштабный прунинг: удаление 8200 пустых точек      |
|  06   |         2 669         |   0.010294   | 1.35 шагов/с | Финальная оптимизация формы (Loss на батче: 0.0088) |

### Анализ границ применимости и режимов деградации:
1. Топологическая сходимость: алгоритм точно восстанавливает глобальную пространственную иерархию (плотная сердцевина сжата внутри менее плотной оболочки, внешние контуры соответствуют эталону). Прунинг сократил вычислительную сложность модели на 75% без деградации ошибки.
2. Эффект гладкого сглаживания: восстановленный объем демонстрирует размытие границ между слоями. Это прямое следствие двух фундаментальных факторов:
	* Экстремальная разреженность данных: 32 проекции покрывают спектральное пространство с критическими пробелами.
	* Низкочастотная природа гауссиан: непрерывные ядра действуют как гладкие базисные функции, что эффективно подавляет высокочастотный лучевой шум разреженной томографии, но естественным образом сглаживает ступенчатые границы при отсутствии специализированных регуляризаторов полных вариаций.

## 6. Структура репозитория

```text

├── src/
│   ├── config.py          # Конфигурация геометрии, лучей и гиперпараметров

├── train.py               # Основной скрипт оптимизации с Densification & Pruning

├── requirements.txt       # Зависимости окружения
└── .gitignore             # Исключение бинарных весов и артефактов
```

## 7. Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/Maxogrammer/xray-gaussian-splatting.git
cd xray-gaussian-splatting
pip install -r requirements.txt
```

### 2. Запуск оптимизации
Синтетический фантом генерируется на лету, скачивание внешних датасетов не требуется:
```bash
python train.py
```
После завершения веса будут сохранены в `gaussians_final.pt`.

### 3. Экспорт в интерактивный WebGL-вьювер
```bash
python -m src.visualizer
```
Скрипт создаст файл `viewer.html`. Откройте его в любом браузере для интерактивного вращения и инспекции восстановленного объема.

### 4. Конвертация в стандартный 3DGS PLY
```bash
python export_ply.py
```
Файл `gaussians.ply` можно открыть в стандартных вьюверах 3DGS (например, SuperSplat).
